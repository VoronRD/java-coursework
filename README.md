# Java Coursework — Computer Devices Management

Приложение для управления компьютерными устройствами и их техническими характеристиками.

## О проекте

Проект разработан в рамках курсовой работы по дисциплине, связанной с объектно-ориентированным программированием и разработкой программного обеспечения.

Приложение предназначено для хранения и управления информацией о компьютерных устройствах, их категориях, производителях, интерфейсах подключения и технических характеристиках.

## Технологии

- Java
- Spring Boot
- PostgreSQL
- Liquibase
- Maven
- JUnit

## Архитектура

Проект построен с разделением ответственности между основными слоями приложения:

- **Models / Entities** — модели и сущности предметной области;
- **DTO** — объекты передачи данных;
- **Repositories** — работа с данными;
- **Services** — бизнес-логика;
- **Mappers** — преобразование объектов;
- **Views / UI** — пользовательский интерфейс.

## Основные возможности

- управление компьютерными устройствами;
- управление категориями устройств;
- хранение информации о производителях;
- работа с техническими характеристиками;
- работа с интерфейсами подключения;
- хранение данных в PostgreSQL;
- управление структурой и начальными данными базы данных с помощью Liquibase.

После настройки базы данных проект можно собрать и запустить с помощью Maven.
