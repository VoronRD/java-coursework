# Computer Devices

Веб-приложение для учёта и управления компьютерными устройствами и периферией.

Проект разработан в рамках курсовой работы на Java. Приложение позволяет работать с компьютерными устройствами, производителями, типами устройств и типами подключения, а также предоставляет возможности поиска, сортировки, фильтрации и просмотра аналитической информации.

## Возможности

- добавление, редактирование и удаление компьютерных устройств;
- управление производителями;
- управление типами устройств;
- управление типами подключения;
- добавление и просмотр пользовательских отзывов;
- поиск устройств;
- сортировка и фильтрация данных;
- аналитическая панель с графиками и ключевыми показателями.

## Технологии

- **Java 21**
- **Spring Boot**
- **Vaadin**
- **PostgreSQL**
- **Spring Data JPA / Hibernate**
- **MapStruct**
- **Liquibase**
- **Maven**

## Архитектура

Приложение построено с разделением ответственности между основными слоями:

- **Services** — бизнес-логика приложения;
- **Repositories** — работа с данными через JPA/Hibernate;
- **MapStruct** — преобразование объектов между слоями;
- **Liquibase** — управление изменениями структуры базы данных;
- **Vaadin** — пользовательский интерфейс приложения.

Взаимодействие с базой данных осуществляется через PostgreSQL.
